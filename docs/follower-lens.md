# 粉丝透镜与新版界面

## 安装与入口
构建 Chrome：`npm run build:chrome`，在扩展管理页加载/重新加载 `dist`。更新后刷新已打开的 X 页面。Firefox 使用 `npm run build:firefox`，最低版本升为 128（MAIN 执行环境要求）；运行仍需 Firefox 实机验收。

主弹窗提供三个功能入口：
- 内容导出：保留单条、批量、多格式与 Obsidian 流程；可以收藏当前内容到稿件库。
- 稿件库：链接采集或 Markdown 导入 → 入库 → X/B站草稿、公众号排版、飞书写入或 ZIP 下载。删除前确认。平台最终发布仍由用户操作。
- 粉丝透镜：独立设置页，按显示方式、关系/规则标签、本地历史、高级选项分组。设置自动保存并同步至已打开页面。

## 粉丝透镜
在 `https://x.com` 浏览信息流、关注/粉丝列表时，插件在已拿到统计的账号旁显示粉丝量。时间线只显示粉丝数和与你的关注关系。鼠标悬停或点击可看关键数据，Enter/Space进入详情，Tab切换、Escape关闭并回焦；详情仅保留关注关系及5类关键数据，已移除更多数据的展开入口。互动样本不足时显示「暂无法判断」，变化是两次记录差而非今日新增。支持自动、同行和独立一行布局；0–3个规则标签和关注倾向开关仅用于账号列表，时间线关系仍由关系开关控制。

关系标签来自 X 返回的关系字段。高粉丝比、粉关接近、新号、老号和样本互动标签采用规则阈值，可在设置中查看说明或关闭；不据此判断账号真伪。浏览量不足 2000 的样本不计算互动率。缺失的统计显示未知或不显示徽标。

本地历史默认关闭。启用后，每账号每 6 小时最多采样一次，最多 40 个点、3000 个账号；基准满 20 小时后可在详情卡查看变化，优先选取接近 7 天前的点。不是后台定时监控，只有浏览并加载该账号数据才会采样。清空后旧待写批次不会恢复，之后的浏览可重新记录。

列表淡化默认关闭；启用后只淡化符合所选规则的列表账号，鼠标悬停或键盘聚焦恢复。主开关关闭时停止展示和采样。旧 twitter.com 域名请改用 x.com。

## 设计取舍与限制
实际 UI 使用文字标题、蓝白界面和文字动作按钮，移除图形品牌 Logo；浏览器工具栏使用默认扩展图标。功能图标及开源版权署名保留。浅色独立页面支持窄屏，主弹窗沿用原有深浅主题。未实施历史提案中的所有高级功能，例如稿件全文预览与批量分发。

当前没有登录 X 的真实账号端到端验收，X 页面结构变化仍可能影响注入；页面缺少统计时不会额外请求数据补全。重新开启后若徽标未出现，请滚动加载新内容或刷新。上游为 [x-follower-lens](https://github.com/yaohongan/x-follower-lens) 0.2.3，MIT；整体项目许可保持原样。

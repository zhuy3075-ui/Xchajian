# 2026-10-10 整合候选版本变更说明

本次为 Xchajian 首次完整源码推送，基于 XClipper 2.8.4，整合渡口 3.3.0 与 x-follower-lens 0.2.3。此前远端只有初始化 README，因此 GitHub 文件差异会包含原项目的完整源码；它不代表所有原有功能都是本次新开发。

## 1. 保留原有内容导出与 Obsidian 工作流

- 保留单条推文、线程、文章、批量导出，以及 Markdown、PDF、HTML、TXT、JSON、CSV 格式。
- 保留本地图片/媒体保存、ZIP 打包、右键和行内入口。
- 保留工作区已有的 Obsidian 完整路径配置、按博主账号归档、目标确认和长文剪贴板交接改动。粉丝透镜整合没有重写这部分业务代码。
- 当前 X 内容可转存稿件库；无法下载的图片会提示，原始 Markdown 仍用于后续排版。

## 2. 合入渡口稿件采集与分发

主要文件：`src/dukou/`、`src/popup/dukou.ts`、`tools/dukou/`。

- 支持微信文章和飞书文档链接采集、本地 Markdown 与图片导入，以及多篇稿件选择。
- 稿件库保存历史记录；同一来源更新，不再仅凭文章标题识别；目录内图片优先与对应稿件匹配。
- 支持 ZIP 下载，包含 Markdown 与相对路径图片。
- 提供 X 文章、B站专栏、公众号排版器填充，以及飞书文档写入。网页适配器只填草稿，最终发布由用户操作。
- 合并后台消息与资源路径；新增来源/目标站点访问按操作请求，取消授权时明确返回失败。
- 加入消息来源校验、文章结构与图片 URL 校验、串行索引更新和抓取任务恢复。
- 保留微信列表内图片，修正同标题覆盖、多目录错图、B站标题定位等问题；飞书部分失败会报告已创建文档，方便继续处理。
- 可选本地终端桥默认关闭；启用后使用 127.0.0.1，回传失败会保留并重试，任务丢失会提示。CLI 与服务文件采用 `.cjs`，兼容项目的 ESM 配置。

## 3. 合入粉丝透镜

主要文件：`src/lens/model.ts`、`parse.js`、`inject.js`、`content.js`、`background.ts`、`popup.html`、`popup.js`、`content.css`。

### 页面显示

- 在 X 信息流与账号列表显示粉丝徽标、粉丝量级配色、可选粉丝/关注比例。
- 显示互关、关注了你等关系；支持账号年龄、比例和当前样本互动规则标签。
- 提供悬停和键盘聚焦详情卡，Escape 关闭。
- 支持自动、同行、独立一行布局，以及 0–3 个标签数量配置。
- 列表淡化默认关闭；开启后，符合所选规则的账号会淡化，悬停/键盘聚焦恢复。
- 明确“样本高互动 / 样本低互动”等标签只反映当前加载样本，不是账号真实性鉴定。

### 数据与稳定性

- 被动观察网页已经发出的 GraphQL 请求，不新增主动粉丝抓取任务，不读取认证请求头。
- 接收包上限为 4 MiB；账号和推文缓存设上限，解析遍历有边界。
- 兼容 legacy 与较新字段结构，校验账号名、计数和日期；缺失或非法数据不伪造为有效统计。
- 关注数为 0 或未知时不计算比例；浏览量累计不足 2000 时不判断样本互动率。
- 重复推文样本可刷新统计，避免累计重复；DOM 节点复用、局部替换和布局变化会清理旧徽标。
- 总开关关闭后同时停止显示和历史采样，清除待保存队列。

### 本地历史

- 默认关闭，仅在用户开启后记录账号名、时间和粉丝数。
- 每账号 6 小时最多一点，最多保留 40 个点、3000 个账号；基准记录至少 20 小时后显示变化。
- 后台串行合并多个标签页的记录，防止整份历史互相覆盖。
- 清空历史时更新代次，使清空前的待写批次失效，避免旧数据恢复。之后的新浏览仍可重新记录。
- 不上传透镜记录，也不进行后台定时监测。

## 4. 实际 UI 调整与 Logo 去除

主要文件：`src/popup/popup.html`、`popup.css`、`popup.ts`、`src/workbench.css`、渡口页面和 `fill-common.js`。

- 主弹窗统一为「内容导出 / 稿件库 / 粉丝透镜」三个入口，复杂设置在独立页面展开。
- 稿件库把「采集入库」和「分发」分开，避免用户未保存就直接选择目标。
- 原来仅靠小图标辨认的稿件操作改为带文字按钮：X 草稿、B站草稿、公众号排版、写入飞书、下载 ZIP、删除。
- 删除增加确认；飞书连接与更多设置使用折叠区域。
- 独立页面使用统一蓝白样式，设置页含示例预览；稿件按钮在窄屏换行，避免内部裁切。
- 移除主弹窗、稿件/导入页面、注入分发面板中的图形品牌 Logo，以及 manifest 的自定义扩展图标。保留文字标题、功能图标和版权署名。
- 本次没有实现旧 UI 提案中的全文预览、批量分发、完整诊断中心等额外功能。

## 5. 构建、兼容性与文档

- `build.mjs` 新增粉丝透镜注入、内容、设置脚本与静态资源构建。
- `src/manifest.json` 在已有 x.com 范围加入 MAIN 与隔离世界内容脚本，不新增必需权限。
- Firefox 最低版本提高到 128，以支持 MAIN 执行环境；旧 twitter.com 域名请使用 x.com。
- README 改为 Xchajian 的真实功能、源码安装、配置和验证说明；增加实际界面截图。
- 更新稿件库/透镜使用说明与隐私说明，保留各上游许可证和修改说明。

# 知拾 2.9.0

知拾用于在 X 页面收藏帖子与评论、导出内容并查看账号信息。这是本整合仓库的首个 GitHub 正式版，推荐使用 Chrome/Edge 桌面版。

## 下载与安装

- 下载 [zhishi-2.9.0-chrome.zip](https://github.com/zhuy3075-ui/Xchajian/releases/download/v2.9.0/zhishi-2.9.0-chrome.zip)，解压到固定目录。
- 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，加载包含 `manifest.json` 的目录。
- 安装包已构建，无需 Git、Node.js 或 npm。浏览器商店版和签名 CRX 不在此次发布范围内。
- 更新时保留原扩展加载目录，备份后更新文件并重新加载；不要先卸载扩展。
- 发布附件 `SHA256SUMS.txt` 用于核对下载文件。完整使用教程见 [README](../../README.md)。

## 主要功能

- 在帖子或评论卡片下保存到 Obsidian、复制正文、按默认格式下载。
- 单条、多选、批量导出；支持 Markdown、TXT、HTML、JSON、CSV，以及页面菜单中的 PDF 打印导出。
- Obsidian 目录授权后静默写入，完成后读回验证，再显示保存回执。
- 讨论页评论按自身 ID 去重，平铺保存到 `09_评论`；保留已有笔记和个人编辑。
- 时间线显示24小时制发布时间；粉丝数、关系标签、账号详情和基于已加载样本的关注建议。
- 粉丝数旁调用 X 原生关注操作，依照返回结果反馈状态。

## 界面与兼容变化

- 插件名称统一为「知拾」，采用新的纸片书签 Logo，并提供本项目 GitHub 入口。
- 弹窗集中为“粉丝透镜 / 导出 / 更多设置”，低频布局、批量参数、文件命名和归档选项默认折叠。
- 采集操作统一在 X 页面完成；旧弹窗操作按钮、稿件库入口和独立粉丝透镜设置入口不再提供。保留模块见 [说明](../optional-integrations.md)。
- 沿用原有配置键，没有新增权限或自动迁移笔记。旧评论重复文件不会自动删除。
- 页面主帖或时间线回复可能按主帖归档；需要作为评论保存时，请在讨论页点击对应评论自身的保存按钮。

## 安全与验证

- 开发依赖 `source-map-js` 1.2.1 → 1.2.2，修复索引 source map 偏移导致的拒绝服务告警；未升级无关依赖。
- 运行时与开发依赖均执行 `npm audit`，2026-10-15 未报告已知漏洞。
- 本地测试结果为698通过、9项显式跳过；缺少私有GraphQL捕获的用例未执行，部分依赖本地HTML样本的历史用例也因样本缺失提前返回。该计数不代表所有真实数据样本已覆盖。
- 构建、设置、页面操作和保存流程另有隔离 Chrome 验证；未执行真实账号全流程。
- X 的登录态、页面结构和限流可能影响采集；关注建议只反映已加载样本，不是账号质量或回关保证。
- Firefox 仅验证构建，没有本次正式安装附件；目录授权静默保存不支持。未提供 Safari 或移动端版本。

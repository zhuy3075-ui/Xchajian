# 保留模块：独立稿件页使用说明

本模块已没有主弹窗入口，不属于当前插件首页教程。普通保存、复制和下载请看 [README](../README.md)；仍需维护独立稿件流程时再阅读本文，完整桥和飞书配置见[补充说明](optional-integrations.md)。

本地整合基于渡口 3.3.0（[上游仓库](https://github.com/alchaincyf/dukou)，提交 `9c530a3c5f469349e45641456fe8b4bf9a257219`），保留原 XClipper 单篇/批量导出功能。

## 加载和入口

执行 `npm run build:chrome`，在 Chrome 扩展管理页加载本项目 `dist` 文件夹。已有安装请点重新加载，并刷新已打开的 X 页面。Firefox 产物由 `npm run build:firefox` 生成在 `dist-firefox`；本次只验证构建，Firefox 浏览器运行尚未实测。

主弹窗已移除“稿件库”和“收藏当前 X 内容到稿件库”两个入口；已有稿件和终端桥保留。高级用户在扩展管理页找到本扩展 ID，打开 `chrome-extension://<扩展ID>/dukou/popup.html` 访问独立稿件页，可收藏该页。X内容需先导出Markdown，再按下文导入。

## 抓取和本地导入

在稿件页粘贴微信 `mp.weixin.qq.com/s` 链接或飞书 `/docx/`、`/wiki/` 链接，点击「采集并存入稿件库」，保存后再选择 X/B站等目标。首次操作时浏览器会请求对应来源和目标网站访问，取消授权会显示失败，不启动抓取。

本地 Markdown：点击「导入本地 md 文件（含图片）」打开导入页；多选 Markdown 和图片，或选择包含它们的文件夹。多篇 Markdown 会提供勾选列表。图片用相对路径且独占一行；本地图必须被选中，浏览器不会读取任意磁盘路径。远程图床需要额外权限时，先输入图片域名并点击授权，再导入。未解析图片在日志中逐项报告。

文章库保存历史稿件，同一 ID 仅保留最新版本；本地稿件按选中的相对路径/文件名识别，CLI按绝对路径识别，不按标题识别。多目录图片优先匹配各自稿件目录，无法唯一匹配时报告错误。单独选择的同名 Markdown 无完整目录信息，会视为同一来源；需要区分时请选所在文件夹。可下载 ZIP（Markdown + `images/`）或删除。数据较多时可主动授权「大容量存储」。不要同时在原渡口插件与此插件运行终端桥。

## 分发

文章行的操作按钮：X、B站、公众号排版器、飞书、下载 ZIP、删除。

- X/B站：授权后打开编辑页，自动填入。X 需要先点 Write 新建 Article 草稿；账号必须具备文章编辑资格。
- 公众号排版器：打开 `editor.huasheng.ai`，将 Markdown 填入左侧输入区。
- 浮动面板可选历史文章并再次填入；既有编辑页需刷新才能加载新授权的脚本。
- 所有网页填充都只操作草稿；图片上传异常会在面板提示，发布由用户检查后执行。
- 填入结束约 1.5 秒后浮动面板自动收起，可点击「稿件库」重新查看结果。图片、封面或标题有异常时显示「⚠ 待检查」并保留明细；执行失败时保持展开。收起只代表本次填入流程结束，不代表目标网站已经保存或发布成功。

## 飞书

在页面底部填写自己拥有的飞书应用 `app_id`、`app_secret`，以及用于文档编辑权限的 `open_id`。密钥保存在浏览器本地存储，未加密，不应在共享浏览器中保存高权限应用密钥；不写入日志或项目记忆。清空并保存可移除配置。

飞书应用需要上游 README 所述的文档读取/创建、图片下载/上传和文档协作者权限，并在飞书管理后台完成权限配置。按钮调用配置的应用身份读取或创建文档。创建后图片上传或编辑权限失败，会报告失败和已创建文档链接，以便人工处理；重试写入会新建另一文档。

读取沿用渡口支持范围：文字、标题、列表、引用、代码、图片；表格、画板、附件等不转换。真实应用权限与飞书租户策略需要用户环境验收。

## 本地终端桥

默认关闭，在「更多设置与使用说明」中勾选开关并授权 `127.0.0.1` 后启用。CLI 和运行方式见 [本地桥说明](../tools/dukou/README.md)。未启用时不会轮询或回传文库。

## 验证边界

当前测试包含单元测试、真实本地桥进程、真实 Chrome 扩展加载、本地导入、ZIP 下载、以及在模拟编辑器中执行上游平台适配器。真实微信、X、B站、飞书账号的端到端交互未执行；网页 DOM 或租户权限变化仍可能要求调整适配器。

在新笔记正文中执行 Obsidian 的插入模板命令。日期变量会在插入时替换；直接复制模板时需要自行填入真实日期，AI 也不能原样留下变量。

## 属性约定
模板以 YAML 属性开头。中文属性名用于本仓库；tags 是 Obsidian 的固定标签字段。

| 属性 | 类型 | 填写规则 |
| --- | --- | --- |
| 类型 | 文本 | X素材、X评论、提炼卡片、个人观点、思考日志、主题地图、选题、博主档案 |
| 状态 | 文本 | 见归档规范，AI 默认待确认 |
| 创建日期 | 日期 | YYYY-MM-DD，按 Asia/Shanghai 的当前日期；不是帖子发布日期 |
| 主题 | 列表 | 仅链接已存在的主题地图，属性内的双链须加引号 |
| 来源笔记 | 列表 | 仅链接已存在原文或证据笔记，可多条 |
| 来源链接 | 文本 | X 素材使用原始帖 URL，其他类型由来源笔记追溯 |
| 帖子ID、作者ID、所属帖子ID、评论ID | 文本 | 数字 ID 用双引号包裹；未知留空，不推测。评论ID用于单条评论，评论集逐条记录 |
| 原帖链接 | 文本 | 评论所讨论的原帖 URL，不用评论链接代替；已保存原帖还应关联来源笔记 |
| 作者账号、作者名称 | 文本 | 按来源记录，不根据昵称推断身份 |
| 发布时间 | 文本 | 保留来源给出的时间与时区；仅有日期就只记录日期 |
| 采集时间 | 文本 | 带时区的时间；不是发布时间 |
| 指标观测时间 | 文本 | 只在实际观察互动指标时填写 |
| 评论覆盖 | 文本 | 未收集、部分可见、已完成本次可见范围；说明限制 |
| 证据状态 | 文本 | 未核验、已对照原文、已外部核验、存在争议、不适用 |
| 观点归属 | 文本 | 原作者、AI解读、AI候选、本人、混合（正文逐条标清） |
| 本人确认 | 复选框 | true 或 false，只有你明确确认后才能设 true |
| tags | 列表 | 简短稳定的分类标签，不带井号 |

链接属性示例：主题: ["[[06_主题地图/主题-X内容研究]]"]。没有适用主题就保留空列表，不生造关联。

## 兼容已有剪藏
已有剪藏若使用英文属性，可原样保留并按下列对应关系读取：

| 已有属性 | 本仓库含义 |
| --- | --- |
| source | 来源链接 |
| handle / author_name | 作者账号 / 作者名称 |
| published | 发布时间 |
| created | 收集日期；不自动当作准确采集时间 |
| description | 剪藏摘要，不等于独立核验结论 |
| likes / reposts / replies / bookmarks / views | 已存互动快照；观测时间若未给出则未知 |

原文中的 author 双链可能没有对应档案；不据此生成身份已确认的博主档案。新素材走标准目录即可进入自动列表；旧素材保留在其他位置时，可按实际文件补充索引链接。

## 模板编辑
编辑模板时建议使用源码模式，保留日期变量的引号，避免属性编辑器误改变量。模板目录不放使用说明，防止插入模板时选到说明文件。

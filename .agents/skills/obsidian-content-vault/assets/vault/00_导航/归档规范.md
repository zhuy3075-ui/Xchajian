# 归档规范

返回 [[VAULT_INDEX|首页]] · 配套 [[00_导航/模板与字段|字段规范]]。

## 保存什么
- 原始素材：作者实际发布的文字、线程、文章、被引用帖与评论，保留来源和可见范围。
- 独立评论：保存到「09_评论」，记录评论者及所属原帖；嵌在原文中的评论可以保持原样，通过引用关联，不重复复制。
- 提炼卡片：从材料中抽出的观点、方法、案例、数据、表达结构；始终注明归属与证据。
- 个人观点：由你提出或明确认可的一个可讨论判断，包含理由、反例与适用边界。
- 思考日志：你自己的问题、联想、犹豫和判断变化；AI 只能整理已提供的想法。
- 主题地图：围绕一个问题组织来源、观点、冲突和缺口。
- 创作选题：读者、问题、角度、素材链与提纲。

## 路径与命名
| 内容 | 正式位置 | 命名方式 |
| --- | --- | --- |
| 新收集原文 | 01_收件箱/原始素材 | X-帖子ID.md；未知 ID 时 收集-YYYY-MM-DD-HHmmss.md |
| AI 候选结果 | 01_收件箱/AI待确认 | 提炼-帖子ID-短标题.md |

| 提炼卡片 | 03_提炼卡片 | 提炼-帖子ID-短标题.md |
| 个人观点 | 04_观点库 | 观点-一句话命题.md |
| 思考日志 | 05_思考日志 | 思考-YYYY-MM-DD-HHmmss-短标题.md |
| 主题地图 | 06_主题地图 | 主题-短标题.md |

文件名不含 Windows 禁用字符：小于号、大于号、冒号、双引号、斜线、反斜线、竖线、问号、星号。长标题缩短，实际标题保留在正文。同名时先核对是否重复；不同材料才加序号，不覆盖旧笔记。

## 去重与来源
- 一条 X 帖子以数字帖子 ID 为键。保存为带引号的文本，避免长整数精度损失。
- x.com 与 twitter.com 下相同帖子 ID 是同一来源；去掉分享链接查询参数后比较。作者改名不代表新来源。
- 线程入口帖子、线程中独立帖子、引用帖、评论各有自己的 ID。可放在同一素材笔记的不同段落，但逐段注明链接和范围。
- 无法确认同一来源时保留候选，标“待核对”；不要按相似标题直接合并。
- 来源更新时追加“补充观察”和观察日期，不抹掉原版本；已有人工文字优先保留。
- 一条原文只留一份。不同主题通过双链关联，不复制全文。

## 状态规则
| 类型 | 可用状态 |
| --- | --- |
| X素材 | 待整理 → 已整理；或已归档 |
| X评论 | 待整理 → 已整理；或已归档 |
| 提炼卡片 | 待确认 → 已确认；或已退回、已归档 |
| 个人观点 | 待确认 → 已确认；或已修订、已归档 |
| 思考日志 | 待继续 → 已整理；或已归档 |
| 主题地图 | 持续维护；或已归档 |
| 选题 | 待选择 → 写作中 → 待发布 → 已发布；或搁置、已归档 |
| 博主档案 | 待核对 → 持续维护；或已归档 |

“状态”和“证据状态”分开：已确认表示你确认采用这张笔记，不表示其中的事实已被外部验证。证据状态统一为“未核验”“已对照原文”“已外部核验”“存在争议”“不适用”；“已外部核验”必须有核验来源、日期和范围，不能笼统代表整篇都正确。

本人在 [[00_导航/集中确认清单|集中确认清单]] 勾选带目标目录的候选操作，即授权该版本候选的正式入档及必要链接更新；不再逐条询问移动权限。授权不包括移动原文、覆盖冲突文件或发布内容。未勾选、内容已变或存在修改意见的条目保持待处理。

## 标签与主题
类型和状态使用属性；主题使用链接列表；标签只留少量稳定的补充分类，例如 平台/X、内容/案例、内容/方法、内容/数据、内容/表达结构。主题尚未建立时，先在正文写“建议主题”，不创建空壳链接。

## 质量底线
原作者声称不等于已证实事实；热度不等于正确；评论样本不代表全部受众；一次互动快照不能推断增长。缺少的数据留空并说明，未知不能填 0。

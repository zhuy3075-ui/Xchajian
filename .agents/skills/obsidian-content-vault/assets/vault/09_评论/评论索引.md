# 评论索引

返回 [[VAULT_INDEX|首页]] · [[02_X素材/X素材索引|原帖素材]] · [[90_模板/模板-X评论|评论模板]]。

保存插件导入或用户提供的真实评论原文，支持按原帖建立子目录。每份评论记录所属原帖、评论者、评论链接或 ID、采集时间和覆盖范围；原帖没有本地文件时保留外部链接，不制造空链接。

## 评论文件（自动汇总）
```query
path:"09_评论/" -file:"评论索引"
```

列表按目录汇总，不要求插件使用中文属性。只有实际导入的内容才会出现；建立此目录不会自动采集评论。

## 保存方式
- 一条评论可保存为「评论-评论ID.md」。
- 同一原帖的一组评论可保存为「评论集-原帖ID-采集时间.md」，时间采用 YYYYMMDD-HHmmss。每条评论在正文保留独立归属与来源。
- 原帖已保存时在“来源笔记”关联其实际笔记；未保存则填写“原帖链接”。无法识别原帖时标记待核对，不猜测。
- 评论已在原素材中完整保存时，先保留引用关系，不为分类重复复制。历史快照可以保留，但分析时按评论 ID 去重，不能当成新增用户意见。

## 提炼与确认
“处理新增素材”会将本目录纳入检查。AI 结合实际读到的原帖上下文，提炼问题、分歧、使用场景和候选需求，结果仍保存到待确认区，由 [[00_导航/集中确认清单|集中确认清单]] 统一确认后入档。

评论者观点、作者观点、AI 解读和本人判断分别标明。部分可见评论不代表全部受众，词频或情绪不能单独证明需求；未读取的评论不补造。

# Xchajian

<img src="assets/branding/xchajian-logo.png" width="80" height="80" alt="Xchajian：交叠纸片与书签组成的蓝色图标">

在 X 页面保存帖子与评论、复制正文、下载内容，并查看发文时间和账号信息。

**这份教程以当前 `pre-release` 的可见界面为准。** 内容操作在 X 页面完成；浏览器工具栏弹窗只负责设置和 Obsidian 目录连接。

[代码仓库](https://github.com/zhuy3075-ui/Xchajian/tree/pre-release) · [问题反馈](https://github.com/zhuy3075-ui/Xchajian/issues) · [来源清单](docs/sources.md) · [许可证](LICENSE.md)

> 当前整合版本为 **2.9.0**，仍在 `pre-release` 分支。推荐 Windows + Chrome/Edge。扩展管理页显示 Xchajian 与蓝色书签图标；上游 XClipper 基线仍为 2.8.4。

## 当前功能和入口

| 想做什么 | 当前入口 |
| --- | --- |
| 保存帖子或单条评论到 Obsidian | X 卡片下方的“笔记＋”按钮 |
| 复制该条正文 | X 卡片下方的双页复制按钮 |
| 按默认格式下载 | X 卡片下方的下载按钮 |
| 临时选择格式、范围或导出 PDF | 下载旁的小箭头，打开“导出当前内容” |
| 多选或批量导出 | X 页面角落的“采集工具” |
| 调整格式、媒体和输出方式 | 工具栏弹窗 → 导出 |
| 调整粉丝徽标、账号卡片和历史 | 工具栏弹窗 → 粉丝透镜 |
| 关注看到的账号 | 点击粉丝数右侧“关注”，在当前页面调用 X 原生关注操作 |
| 连接 Obsidian、设置保存目录 | 工具栏弹窗 → 更多设置 → Obsidian |

弹窗顶部现在只有 **粉丝透镜 / 导出 / 更多设置** 三个分区。页面控件默认显示，设置修改后自动保存。

旧教程中的弹窗“复制 / 下载 / 导出 PDF / 添加到 Obsidian”操作按钮、稿件库入口、收藏当前内容入口、独立粉丝透镜设置页，以及页面控件开关和左右位置选择，均已移除。请使用上表中的当前入口，不必寻找这些旧控件。商店评分和上游跳转链接也已移除；标题旁的 GitHub 链接仅打开本项目仓库，版本号显示在名称下方。

## 安装插件

### 1. 准备环境

| 用途 | 所需环境 |
| --- | --- |
| 构建插件 | Git、Node.js 与 npm；Node 22.x 至少 22.22.2，或 24.x 至少 24.15.0 |
| 使用插件 | Chrome/Edge 桌面版，允许加载已解压扩展，能正常访问并登录 X |
| 保存到笔记库 | 自己的 Obsidian 本地仓库，仅在使用保存功能时需要 |

普通浏览、复制和导出无需 AI、Python、API Key、数据库或本地终端桥。只有使用配套建库脚本才需要 Python；已有库可以直接连接。

以下命令以 Windows PowerShell 为例。先检查 `git --version`、`node --version` 和 `npm --version`；若 PowerShell 阻止 `npm.ps1`，可使用 `npm.cmd`。

### 2. 获取并构建

```powershell
git clone --branch pre-release https://github.com/zhuy3075-ui/Xchajian.git
cd Xchajian
npm ci
if ($LASTEXITCODE -ne 0) { throw '依赖安装失败' }
npm run build:chrome
if ($LASTEXITCODE -ne 0) { throw '构建失败' }
Test-Path ./dist/manifest.json
```

最后应输出 `True`。也可下载 `pre-release` 分支 ZIP，解压后在有 `package.json` 的目录执行安装和构建。不要把私有笔记库放进源码目录。

### 3. 加载到浏览器

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启开发者模式，点击“加载已解压的扩展程序”。
3. 选择构建后的 **`dist` 文件夹**，不是源码根目录。
4. 固定扩展到工具栏，打开并登录 X，再刷新页面。
5. 检查帖子下的保存、复制、下载按钮，以及页面角落的“采集工具”。

工具栏弹窗应显示三个设置分区，正常宽度为 416px。更新扩展后，已打开的 X 页面需要刷新；刷新前先保留未发送的草稿。

Firefox 可执行 `npm run build:firefox`，在 `about:debugging#/runtime/this-firefox` 临时加载 `dist-firefox/manifest.json`。要求 Firefox 128+；目前仅验证构建，目录授权静默保存不支持，使用下载功能。没有 Safari 或手机安装包。

<a id="usage"></a>
## 在 X 页面使用

### 复制一条帖子或评论

点击该卡片下方的双页复制按钮。复制的是这条内容自身的纯文本，保留换行，不包含引用帖、图片、作者信息或相邻评论。若正文无法在原处展开，先打开详情再复制。

### 下载一条内容

1. 在弹窗“导出 → 单条导出”选择默认单条格式。
2. 回到 X，点击目标卡片的下载按钮，直接开始该条导出。
3. 需要另外选择格式时，点击下载旁的小箭头，在页面菜单中选择格式、范围，再点击“下载文件”。

| 格式 | 适用情况 | 入口与限制 |
| --- | --- | --- |
| Markdown、TXT、HTML、JSON、CSV | 笔记、阅读或数据处理 | 默认单条格式、页面导出菜单和批量面板 |
| PDF | 打印排版 | 仅页面单条导出菜单；进入浏览器打印预览后手动另存为 PDF |

页面菜单中的“复制”会按当前选择的格式复制，PDF 不提供复制。选择非 PDF 格式会同时更新后续单条下载的默认格式；批量格式单独保存。面板按内容自动调整高度，右上角或 Esc 可关闭；手动操作的结果显示在面板内，文件名较长时悬停可查看完整名称。

默认范围是“仅此条”。选择“作者线程”时尝试补全同作者连续发文，不包含其他人的回复。折叠长帖或文章预览可能打开临时详情页补全，完成后释放临时页。请等结果提示，不要在采集中关闭或刷新原页面。“已发起下载”表示下载任务已交给浏览器，可在浏览器下载记录中确认完成。

### 多选或批量导出

**只导出挑选的内容：** 打开“采集工具” → “选择多条”，勾选目标卡片，然后在页面底部的选择条中选格式，点击“导出所选”。完成后可回“采集工具”查看进度。

**导出本页列表：** 打开“采集工具”，选择格式和“本页已加载列表”，点击“开始导出”。这会处理面板识别到的列表，不是多选框中的子集。

在面板中查看进度、暂停或停止任务。普通任务可暂停；自动采集任务可停止。

收起面板不会停止任务。“重置导出去重记录”需要确认，重置后可能再次下载已导出的内容，不会删除磁盘文件。批量导出不是批量保存评论到 Obsidian；保存单条评论请使用评论自身的“笔记＋”。

如果需要“按设置自动翻页”，先在弹窗“导出 → 批量导出 → 批量采集与输出”选择 Auto/Super 及范围，再回页面面板开始。该方式支持书签、喜欢和个人资料页的帖子，不支持首页时间线；需要相应站点权限及 X 登录会话。没有这类需求时保持默认手动方式即可。

### 查看时间与账号信息

- 发文时间显示为本地时区的 24 小时制 `MM-DD HH:mm`，跨年补年份；悬停可看秒和时区。
- 时间线上显示粉丝数和与你的关系；悬停、点击或键盘聚焦徽标可打开账号详情。
- 点击粉丝数右侧的“关注”，直接调用当前账号行或帖子菜单里的 X 原生关注操作，保留当前页面。处理时显示“关注中…”，收到成功响应后显示“已关注”；私密账号等待批准时显示“已请求”。已知已关注的账号不可重复操作，可识别的自身账号不显示控件。未确认结果时会提示查看 X 提示或刷新，不自动重试；X 要求的登录、确认或限制仍按原生流程处理。
- 账号卡片的数据来自浏览时已加载的内容，不代表持续监测或对账号真实性的判断。规则含义见[粉丝透镜说明](docs/follower-lens.md)。

## 连接 Obsidian 并保存

### 1. 准备自己的仓库

已有 Obsidian 仓库可以直接使用。没有仓库时，先用 Obsidian 创建或打开一个本地文件夹，使根目录生成 `.obsidian`。例如：

```text
D:\Knowledge\我的智库\
├─ .obsidian\
├─ 02_X素材\
└─ 09_评论\
```

素材和评论目录可以在保存时创建。需要完整空白模板和自动查询索引时，另见[可选建库教程](docs/obsidian-workflow.md)；它不是保存功能的必装步骤。

### 2. 连接目录

1. 打开工具栏弹窗 → **更多设置 → Obsidian**。
2. 在“素材保存目录（完整路径）”填写自己的目标，例如 `D:\Knowledge\我的智库\02_X素材`。
3. 按需展开“归档选项”，开启“按博主账号建立文件夹”，检查“保存位置示例”。
4. 点击“连接仓库，启用静默保存”。
5. 在连接页把“仓库完整路径”改为自己的根目录，例如 `D:\Knowledge\我的智库`。
6. 点击“选择仓库并允许写入”，在系统选择器选择同一个根目录，并授予写入权限。

连接页选择的是含 `.obsidian` 的根目录，不能选择 `02_X素材` 子目录。页面预填路径只是示例，需要替换；浏览器不返回完整磁盘路径，同名目录请自己核对位置。

也可使用相对素材目录 `02_X素材`，但需展开“归档选项 → 使用仓库名称配置（相对目录）”并填写实际库名。主帖目录必须位于已连接仓库内。权限失效时重新连接。

### 3. 保存并检查文件

回到 X，点击帖子下方的“笔记＋”。成功后右下角显示文件位置，不唤起 Obsidian，也不逐条弹出确认。只有写入、关闭并读回一致才报告成功；失败时按提示连接目录或重试。

| 内容 | 保存位置 |
| --- | --- |
| 主帖或文章 | 设置的素材目录；开启作者分组时进入作者账号子目录 |
| 讨论页中所选评论 | 当前仓库下的 `09_评论/评论者账号-评论ID.md`，不再按评论者新建文件夹 |

评论按自身来源 ID 去重，重复点击指向已存文件，保留首次快照和个人编辑。旧重复文件不会自动清理。主页时间线里的回复，或单独打开后作为页面主帖的回复，可能按主帖归档；要按评论保存，应在讨论页点击该评论自身按钮。

首次保存后，按回执路径在磁盘或 Obsidian 中检查正文。普通已有库不一定有“评论索引”或“X素材索引”；这些来自可选模板，缺少索引不代表没有落盘。

静默保存写入 Markdown 和远程媒体链接。若需要离线图片/视频，应使用 Markdown 下载，配合“本地保存”和 ZIP；静默保存不会自动下载所有附件。

## 调整插件设置

| 主分区 | 子分区或选项 | 用途 |
| --- | --- | --- |
| 粉丝透镜 | 显示 | 浏览增强总开关、分级配色、关注建议分级、账号详情卡、徽标布局等 |
| 粉丝透镜 | 标签 | 选择账号列表规则标签和淡化选项 |
| 粉丝透镜 | 历史 | 启用本地采样、查看记录数、清空历史；高级选项中有调试计数 |
| 导出 | 单条导出 / 批量导出 | 分别设置默认格式；批量还可调整转帖、输出和采集策略 |
| 导出 | 通用导出选项 | 本地媒体、互动数据、元数据与 ZIP，默认折叠 |
| 更多设置 | 下载 | 下载子目录、文件名模板与预览 |
| 更多设置 | Obsidian | 目录连接、素材路径、作者分组、相对路径库名、标签 |
| 更多设置 | frontmatter 字段 | 控制导出 Markdown 的 YAML 属性 |
| 更多设置 | 页面工具 | 当前仅保留“导出后关闭标签页”选项，不提供页面控件开关或位置选择 |

常用开关和默认格式保持直接可见；低频选项默认折叠，原有配置继续生效：

- 粉丝透镜 → 显示 → **布局与标签数量**：徽标布局、规则标签数量。
- 导出 → **通用导出选项**：媒体、互动数据、元数据与 ZIP。
- 导出 → 批量导出 → **批量采集与输出**：转帖、合并方式、采集策略与范围。
- 更多设置 → 下载 → **文件命名**：命名模板与预览。
- 更多设置 → Obsidian → **归档选项 / 标签设置**：笔记字段、按作者归档、仓库名称与标签。

更多设置每次展开一组；模板字段仍在 Frontmatter 分组内。不要把“单条 / 批量”设置页当作开始采集按钮，实际导出在 X 页面进行。

粉丝历史默认关闭，开启后只在浏览取得数据时采样，保存在本机。没有足够跨度的历史时显示等待记录；“比约 N 天前多/少”是两次样本差，不能当作实时新增粉丝数。

开启“显示关注建议分级”后，关注/粉丝等账号列表显示 **A · 优先了解、B · 按需了解、C · 先观察**；互动样本不足则显示“待判断”。悬停标签可看依据。分级是基于已加载样本的浏览建议，不是内容质量评分或回关预测；具体规则见[透镜说明](docs/follower-lens.md#关注建议分级)。设置中已移除“这些标签如何计算？”说明区，保存状态反馈继续保留。

## 更新与备份

在原源码目录更新，保持原来的加载路径：

```powershell
git status --short
git pull --ff-only origin pre-release
if ($LASTEXITCODE -ne 0) { throw '更新失败，先处理本地改动或分支分歧' }
npm ci
if ($LASTEXITCODE -ne 0) { throw '依赖安装失败' }
npm run build:chrome
if ($LASTEXITCODE -ne 0) { throw '构建失败' }
```

然后在扩展管理页点击“重新加载”，再刷新 X。不要为了更新先卸载扩展；卸载或更换浏览器配置可能丢失设置、历史和目录授权。

- 备份笔记时备份整个 Obsidian 仓库，包含附件及自己的 `.obsidian` 配置；不要上传到本公开仓库。
- Git 克隆不包含浏览器设置、粉丝历史或目录授权。换电脑后需重新加载扩展并授权目录。
- 模板更新不会自动改写已有笔记。个人源码改动应先保存，更新冲突时不要强制重置。

<a id="troubleshooting"></a>
## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 按旧截图找不到按钮 | 以本文入口表为准；当前弹窗只做设置，保存和下载在 X 卡片下方 |
| 找不到 manifest | 构建成功后加载 `dist`，不是源码根目录 |
| npm 提示 EBADENGINE | 检查 Node 小版本是否满足安装要求 |
| 页面没有新增按钮 | 确认加载本仓库的最新 `dist`，重载扩展并刷新 X |
| 弹窗窄成一条或仍是旧版界面 | 重新构建、核对加载路径、重载扩展，再关闭重开弹窗 |
| 保存提示未连接 | 在“更多设置 → Obsidian”连接；填写路径不等于授予写入权限 |
| 保存成功但没看到文件 | 按回执路径查磁盘，核对实际连接的同名库；索引可能未配置或未刷新 |
| 评论未进入 `09_评论` | 在讨论页点击评论自身按钮；独立详情页的主帖可能按主帖归档 |
| 重复保存评论没有新文件 | 正常去重；查看提示中的已有文件 |
| 点击下载打开详情页 | 可能正在补全折叠正文，等待结果提示；失败时查看错误，不必再次重复点击 |
| PDF 没有直接落盘 | 需要在浏览器打印预览中选择另存为 PDF |
| 下载图片离线不可见 | 用 Markdown + 本地图片/媒体 + ZIP；静默保存只保留远程链接 |
| 自动翻页无法启动 | 检查页面来源、Auto/Super 设置和站点权限；首页时间线不支持 |
| 仍弹出 Obsidian 软件 | 核对是否同时启用了旧版或原上游扩展；当前保存链路是目录授权写入 |

报告问题请提供系统、浏览器、`git rev-parse --short HEAD`、实际点击入口及错误原文。不要上传密钥、浏览器配置或整个私有笔记库。

## 开发与验证

```powershell
npm ci
npm run typecheck
npm run build:chrome
npm run build:firefox
```

公开仓库尚未随附完整 `tests/` 和浏览器验收脚本，`npm test` 不代表新克隆即可完整复现开发者本地测试。当前主验证环境为 Windows / Chrome；Firefox 仅构建，其他系统及真实账号全流程需自行验收。

新安装时逐项检查：

- [ ] 工具栏弹窗三个分区可切换，无旧操作按钮或第三方推广入口。
- [ ] X 卡片下的复制、默认格式下载和页面导出菜单可用。
- [ ] “采集工具”可识别当前已加载内容并显示导出进度。
- [ ] 使用保存功能时，授权库内能读到短帖正文；讨论页评论进入 `09_评论`，重复点击不新增副本。

设置和粉丝历史保存在浏览器本地；素材写入授权目录。远程媒体和目标平台会使用网络。配套 AI 是否发送内容给模型，取决于所选 AI 工具，详见[隐私说明](PRIVACY.md)。

- 智库搭建：目录、原生索引、8模板、AI协议与“候选自动保存→用户集中确认→按需正式入档”，整理为`obsidian-content-vault`。分发空白模板，不含私人笔记。

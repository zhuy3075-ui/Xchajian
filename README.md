# Xchajian

将 X 内容导出、稿件采集分发和粉丝透镜整合到一个浏览器扩展中。

当前为 **pre-release 候选版本**，基于 XClipper 2.8.4、渡口 3.3.0 和 x-follower-lens 0.2.3。已完成本地检查及隔离 Chromium 验证；真实账号流程和 Firefox 实机运行仍需验收。此仓库是整合版，原项目商店安装包不包含这里的新增功能。

## 功能

| 功能区 | 能做什么 |
| --- | --- |
| 内容导出 | 单条/线程/文章与批量导出；Markdown、PDF、HTML、TXT、JSON、CSV；本地图片/媒体与 ZIP；Obsidian 保存 |
| 稿件库 | 当前 X 内容入库，微信/飞书链接采集，本地 Markdown 图文导入，历史稿件管理和 ZIP 下载 |
| 稿件分发 | 填入 X 文章、B站专栏草稿及公众号排版器；使用自行配置的飞书应用写入文档；可选本地终端桥 |
| 粉丝透镜 | 信息流/账号列表粉丝徽标、关注关系、规则标签、悬停或键盘详情、本地粉丝变化记录 |

UI 使用「内容导出 / 稿件库 / 粉丝透镜」三个入口；独立页面统一蓝白风格，稿件操作带文字标签，窄屏自动换行。已移除图形品牌 Logo，保留文字标题和功能图标。

## 安装开发版

准备 Node.js 22.13+（建议 24）和 npm，然后执行：

```sh
git clone --branch pre-release https://github.com/zhuy3075-ui/Xchajian.git
cd Xchajian
npm ci
npm run build:chrome
```

1. 打开 Chrome / Edge 的扩展管理页面，开启开发者模式。
2. 点击「加载已解压的扩展程序」，选择生成的 `dist` 文件夹。
3. 打开 `https://x.com`；升级扩展后，重新加载扩展并刷新已打开的 X 页面。
4. 点击扩展按钮，选择「内容导出」「稿件库」或「粉丝透镜」。

Firefox 构建：`npm run build:firefox`，产物在 `dist-firefox`。最低 Firefox 128；当前只验证构建，尚未验证 Firefox 实机运行。仓库不提交 node_modules、dist 或浏览器用户数据，需自行构建；当前没有发布商店更新或 Release 安装包。

## 使用与配置

- **稿件库**：先采集或导入，再通过每篇稿件的文字按钮分发。X/B站填入草稿后由用户检查并发布。见 [稿件库说明](docs/dukou.md)。
- **粉丝透镜**：徽标默认开启，历史记录和列表淡化默认关闭。只处理 X 页面已经加载的数据，不主动抓取整份粉丝列表。规则标签和互动率仅描述已加载样本，不判断账号真实性。见 [粉丝透镜说明](docs/follower-lens.md)。
- **本地历史**：每个账号每 6 小时最多采样一次，最多 40 个点、3000 个账号；关闭总开关即停止采样，清空会使先前待写批次失效。
- **飞书**：按页面说明配置自己的应用；应用密钥仅保存在浏览器本地，未加密。所需权限由自己的飞书租户管理。
- **本地终端桥**：默认关闭，启用时单独授予 127.0.0.1 权限。见 [CLI 与桥说明](tools/dukou/README.md)。

> **首次连接 Obsidian 静默保存：** 在插件的 Obsidian 设置点击「连接仓库，启用静默保存」，核对仓库完整路径（当前为 `E:\x-obsidian\X智库`），选择对应的仓库根文件夹并允许写入。此操作使用 Chrome/Edge 的原生目录授权，浏览器若提供访问时长可选择始终允许；授权失效时重新连接。浏览器不提供所选目录的绝对路径，请自己核对文件夹位置。
>
> 主帖在「素材保存目录」沿用原路径/作者分组；目标必须在已连接仓库内。相对路径仍可用，填写的 Vault 名须与所选仓库一致。评论使用下述固定目录。Firefox 当前不支持此目录授权方式，会明确提示，仍可使用普通 Markdown/ZIP 导出。无需 Obsidian 插件、本地服务或剪贴板。

**评论/推文卡片一键保存：** 开启「在推文上显示内联按钮」后，点击卡片分享/下载按钮旁的「笔记＋」，只保存点击的这一条。普通完整卡片直接采集；时间线上的折叠长帖和长文预览自动打开后台临时详情页，采集后关闭，不打开作者主页。评论区保持当前页面，仅展开所选评论。在讨论页采集其他评论时，一条评论一篇笔记，统一存到本地版指定的 `E:\x-obsidian\X智库\09_评论`，文件名固定为 `作者账号-评论ID.md`，不再按作者创建子文件夹；此评论路径独立于弹窗的主帖素材目录。主帖和首页普通卡片仍使用原有归档设置。保留正文、图片远程链接、作者、时间、评论原链接和采集时的讨论页链接，不采集相邻评论；引用内容保留被引用作者。评论笔记另附采集时间、单条范围说明及 `[[09_评论/评论索引|返回评论索引]]`；现有评论索引按 `09_评论` 目录自动汇总，新评论落盘后即可在阅读视图查看。评论正文折叠时自动尝试原地展开，展开失败会明确提示，避免把摘要当作全文；不会点击引用帖的展开按钮或跳到其他评论。

**时间线上看不到保存按钮：** 打开扩展弹窗，点击「添加到 Obsidian」，插件会开启并补回卡片按钮。关闭弹窗后，点击目标帖子的「笔记＋」保存；弹窗本身不会猜选时间线上的某条帖子。若提示刷新，请刷新 X 页面让新版脚本生效。X 重绘操作栏时，按钮会自动补回，不重复添加；设置中仍可关闭内联按钮。

**静默保存与结果提示：** 卡片、弹窗、文章页和右键的 Obsidian 入口直接写入已授权目录，不打开 Obsidian、不跳转应用、不因页面失焦而暂停。浏览器文件流关闭后，重新打开目标文件并读回正文一致才显示「保存成功」；提示同时列出仓库内的实际文件位置（含另存编号），卡片和右键提示约 5 秒后消失。未授权或写入失败时显示原因并保留正文。卡片未连接目录时只提供连接/关闭入口，避免无效重试；点击连接后选择仓库并授权，返回原页面会自动继续保存（请保持原页面打开）。其他写入错误仍可重试；弹窗提供重试/连接入口，不自动回退到应用链接。

**提示成功但找不到：** 按成功提示中的「位置（仓库内）」在已连接仓库中查找。当前主帖通常进入 `02_X素材/作者账号/`，评论进入 `09_评论/`；首页“待处理原始素材”只查询 `01_收件箱/原始素材/`，不会展示前两处内容。可在 Obsidian 打开「X素材索引」或「评论索引」并切换阅读视图；保存成功仅代表文件正文已写入并读回验证，不代表 Obsidian 的索引或当前界面已刷新。

**评论去重：** `09_评论` 内按评论原链接的 ID 去重。采集时间、互动数、显示语言或账号名称变化时，重复采集会提示「已保存，无需重复保存」，并显示已有文件位置；保留首次保存及你手工补充的内容，不自动更新或另存副本。兼容已有编号文件及账号改名后的旧文件；请保留文件名中的评论 ID 和来源链接，删除原笔记后可以重新采集。只枚举评论目录的文件名，并读取匹配 ID 的候选笔记核对自身来源，不把引用帖 ID 当评论 ID。历史重复文件不会自动删除。

**主帖同名笔记：** 沿用同内容复用、不同内容另存 `作者-ID (2).md` 的规则。扩展内写入串行，检测到外部程序在写入期间更改文件会中止。浏览器 API 不提供跨应用原子锁，不应让其他程序同时写同一目标文件。

**完整长文：** 文章页操作栏和扩展弹窗保留全文采集。需要临时详情页的流程仍在结果交回原页面后关闭插件创建的临时页；用户自己打开的页面保持打开。采集失败、原页面不再接收或目标推文改变时保留临时页。

**评论一键复制：** 开启「在推文上显示内联按钮」后，点击卡片「笔记＋」旁的双页图标「复制正文」。评论和普通时间线卡片均可使用，只复制所选卡片自身的纯文本，保留换行、表情和可见链接文字，不附加作者、互动数、引用帖、图片或相邻评论。折叠评论会尝试原地展开；需要跳转的全文入口请先进入详情页再复制。成功后右下角提示「正文已复制」，不打开新页面、不保存到 Obsidian。剪贴板拒绝、页面失焦或展开失败时明确提示失败，不把截断内容当成复制成功。

**时间线发文时间：** 帖子卡片原来的相对时间（如「20小时」）改为电脑本地时区的 `MM-DD HH:mm`，使用24小时制；跨年帖子补充年份。悬停可查看完整年月日、秒和时区。滚动加载及X重绘后自动恢复，不依赖「内联按钮」开关；保留原始发文时间属性和帖子链接，不改变导出时间数据。没有有效原始时间的卡片保持原样。

**账号详情卡：** 时间线只显示粉丝数和与你的关注关系（可关闭关系标签），老号、比例及样本标记收进详情。悬停或点击徽标，先看关注关系、粉丝人数、TA关注的人、粉丝变化、注册月份和互动表现；展开「查看更多数据与计算说明」再看比例、累计发布、具体对比时间及采样计算依据。互动数据不足时显示「暂无法判断」。变化是本次读取与历史基准的差，不是今日新增；历史默认关闭，未开启时明确显示。可将鼠标移入卡片操作；键盘Enter/Space进入、Tab到展开项、Escape关闭并回到徽标。
**账号列表关注倾向：** 原showRatio及规则标签开关继续作用于关注/粉丝列表。粉丝/关注大于1.25为「被关注更多」，小于0.8为「关注别人更多」（倍数为关注/粉丝），中间为「粉丝与关注相近」。人数相近不代表互关，不能由比例判断影响力或回关意愿。

静默保存专项：132 项相关用例通过，覆盖目录权限、路径边界、完成回包、落盘后读回校验、成功位置提示、失败重试、授权后自动恢复、时间线按钮重绘恢复及弹窗入口、折叠正文分阶段加载、时间线临时详情页、单评论归属、评论ID去重与索引回链。隔离 Chromium 用合成 X 页面与 OPFS 真实文件句柄验证 IndexedDB 连接、后台写入/关闭/读回、失焦保存及同名保护，无页面错误。目录选择器使用测试替身；原生目录选择、权限续期和真实 Obsidian 仓库写入仍待用户验收。

评论复制专项：新增11项用例，与上述保存用例共143项通过；独立复核34项通过。隔离Chromium用实际扩展验证原生剪贴板写入/读回、折叠展开、按钮重绘和键盘复制，3组检查通过。真实X页面和Firefox剪贴板尚未实机验收。

发文时间专项：48项时间显示、复制与保存相关用例通过（含时间显示前后引用作者及导出内容不变）；隔离Chromium验证本地时区/午夜、动态重绘、跨年、窄屏和夏令时转换，4组检查通过。真实X页面布局及Firefox实机尚未验收。

关注含义专项：18项边界用例及37项原透镜用例，共55项通过；隔离Chromium以合成X数据验证三类含义、反向倍数、键盘详情、自动布局/390px窄屏、零值与缺失数据更新及原设置兼容，4组检查通过。尚未验收真实账号页面。

## 隐私与权限

数据默认保存在本地浏览器。分发稿件、写入飞书或下载远程图片时，会与所选目标服务通信。新增站点按需授权；透镜使用已有 x.com 范围，不新增必需权限。不提交应用密钥、访问令牌、个人浏览器配置和真实账户抓包数据。Obsidian 静默保存只访问用户在浏览器明确授权的仓库目录，目录句柄与对应路径保存在扩展本地 IndexedDB。为避免重复文件，会读取目标同名笔记进行比较；评论还会枚举 `09_评论` 文件名并读取匹配 ID 的候选笔记核对来源，不扫描整个仓库、不上传笔记。现有 `clipboardWrite` 仅保留给复制等操作，Obsidian 保存不读写剪贴板。完整说明见 [PRIVACY.md](PRIVACY.md)。
